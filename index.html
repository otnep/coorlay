УстановкаInstallation

  1. Скачайте APK и скопируйте его на флешку (FAT32). Download the APK and copy it to a USB stick (FAT32).
  2. Если стоят прежние сборки coorlay 0.0.x (пакет com.shihab.diplay.coolray43), удалите их: версия 1.0.0 ставится отдельным приложением, и две копии будут мешать друг другу. If an earlier coorlay 0.0.x build is installed (package com.shihab.diplay.coolray43), uninstall it: 1.0.0 installs as a separate app, and two copies get in each other's way.
  3. Установите APK файловым менеджером магнитолы — или с флешки от root: так же исправляется Wi-Fi Direct. Install the APK with the head unit's file manager — or as root from a USB stick (in Russian), which also fixes Wi-Fi Direct.
  4. Подключите iPhone кабелем или выберите «Беспроводное подключение». Для беспроводного сначала выполните сопряжение iPhone в штатном меню Bluetooth магнитолы. Connect the iPhone with a cable or choose "Wireless connection". For wireless, first pair the iPhone in the head unit's own Bluetooth menu.
