УстановкаInstallation

Переход на 1.0.4Updating to 1.0.4

У версии 1.0.4 новая подпись APK. При переходе со старой официальной версии сначала удалите её. Настройки и сопряжения, сохранённые в приложении, при этом сбросятся.

Version 1.0.4 uses a new APK signing key. Uninstall the earlier official version before updating. This resets the settings and pairings stored in the app.

  1. Скачайте APK и скопируйте его на флешку FAT32. Download the APK and copy it to a FAT32 USB stick.
  2. Установите APK через файловый менеджер магнитолы. Для автоматической установки с флешки есть архив для USB и инструкция. Install the APK with the head unit's file manager. For automatic installation from a USB stick, see the USB installer and its guide (in Russian).
  3. Откройте coorlay и выберите «Подключение по USB». Для беспроводного режима сначала сопрягите iPhone в штатном меню Bluetooth и нажмите «Беспроводное подключение». Open coorlay and choose “USB connection”. For wireless, pair the iPhone in the head unit's Bluetooth menu first, then choose “Wireless connection”.

Wi-Fi Direct не включается?Wi-Fi Direct does not turn on?

Для H30 есть отдельный USB-архив с исправлением Wi-Fi Direct. На H50 используйте v8 только для указанной в инструкции сборки прошивки. Чтобы подключаться через точку доступа магнитолы, выключите Wi-Fi Direct в настройках coorlay. A separate USB archive provides the Wi-Fi Direct fix for H30. On H50, use v8 only on the firmware build listed in the guide. To connect through the head unit's hotspot, turn off Wi-Fi Direct in coorlay settings.
